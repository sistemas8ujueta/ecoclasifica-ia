# EcoClasifica IA

Aplicación web para la clasificación de residuos, proyecto académico de la Corporación Universitaria Reformada de Barranquilla.

El proyecto vive en [`ecoclasifica-web/`](ecoclasifica-web/) — ver ese directorio para instrucciones de instalación y ejecución.

`database/app.db` contiene la base de datos SQLite compartida por el backend.
